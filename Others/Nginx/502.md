# Others Nginx Troubleshooting

## 1. 502 / 503 Bad Gateway

```bash
nginx -t                      # config test
systemctl status nginx
tail -f /var/log/nginx/error.log
ss -tlnp | grep -E ':80|:443'
```
- 502/503: backend (php-fpm, app server) down or socket permission wrong (`/run/php-fpm/www.sock`)
- 403: file permission, `chown www-data`, SELinux context (`restorecon -Rv /var/www`)

## 2. Certbot SSL renewal fails

- Port 80 not reachable, webroot path wrong — `certbot renew --dry-run`
